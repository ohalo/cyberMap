收录范围Scope

收录对象 Agent harness 本体：模型之外负责循环、执行器、上下文/记忆、审批门与沙箱的那一层，包含 CLI 编码代理、IDE/桌面代理、个人助理/通用代理、多代理编排平台、框架/SDK/运行时五类。插件、技能包、MCP 服务、教程、榜单、评测基准、模型中转/网关不进榜。The unit of ranking is the harness itself — the loop, executors, context/memory, approval gates and sandbox around a model. Five categories: CLI coding agents, IDE/desktop agents, personal/general agents, multi-agent orchestration, and frameworks/SDKs/runtimes. Plugins, skills, MCP servers, tutorials, benchmarks and proxy gateways are excluded.

人工校验清单是权威发现源；GitHub topic 查询只提供候选，必须同时命中 harness / coding agent / agent runtime 等本体词并通过排除词过滤，才进入榜单，标记为「自动发现」。闭源产品没有公开仓库指标，进观察名单，不参与数值排名。The curated catalog is the authoritative discovery source. GitHub topic queries supply candidates only; they must contain harness-specific signals and pass an exclusion filter before entering with a "Discovered" badge. Closed-source products without verifiable metrics go to the watchlist, not the numeric ranking.

Score = 100 × Σ(wᵢ × normᵢ) / Σ(wᵢ 可用)。分位归一化避免头部项目碾压长尾；npm 下载量缺失时只在 reach 内部重归一；首日无历史快照时 momentum 整体剔除并在其余维度间重归一，绝不填 0 假装没有数据。Score = 100 × Σ(wᵢ × normᵢ) / Σ(available wᵢ). Percentiles prevent head projects from dominating the long tail; missing npm downloads are renormalized inside reach; without a history snapshot, momentum is removed and remaining weights renormalized — never filled with a fake zero.

降权与反作弊Penalties & anti-gaming

  • 归档仓库 ×0.80；fork 仓库 ×0.90；创建不足 14 天 ×0.85；同组织批量仓库 ×0.97。Archived ×0.80; fork ×0.90; newer than 14 days ×0.85; bulk repos from one owner ×0.97.
  • 单日 stars 增量 > 2000 且 > 现有 stars 的 10% 时 ×0.90，标记「待观察」。Daily star delta > 2000 and > 10% of current stars → ×0.90, flagged for observation.
  • 仓库元数据 7 天缓存；确认查不到的 slug 也缓存，不每天重试。GitHub REST 有额度保护，单日最多 12 次兜底补查。Repo metadata is cached for 7 days, including confirmed misses. REST probes are capped at 12 per run to respect rate limits.
