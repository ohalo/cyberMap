字段表

sites.json 顶层含 schema / site / counts / categories / group_index / sites。下面是 sites[] 每条的字段。

字段类型说明
namestring站点名称
urlstring官网或仓库地址
categorystring分类 key，如 aiChat / dailyAI_oss
category_namestring分类中文名
groupstring所属父分组
datestring|null收录日期 YYYY-MM-DD，无尾注则为 null
tagsstring[]方向标签，最多 3 个（与 /daily/ 卡片一致）
verifiedobject|null验证证据：http_status / stars / ai_hits / date / checked_at
healthstring|null站点健康态：ok / down / unverified

调用示例

拿全量数据，筛出带验证证据的 RAG 类站点：

# 全量目录
curl -s https://cybermap.halo26812.eu.org/data/sites.json | jq '.counts'

# 只看带验证证据、且打了「RAG 检索」标签的站点
curl -s https://cybermap.halo26812.eu.org/data/sites.json   | jq '[.sites[] | select(.verified != null and (.tags | index("RAG 检索")))]         | map({name, url, stars: .verified.stars})'
import json, urllib.request

url = "https://cybermap.halo26812.eu.org/data/sites.json"
data = json.load(urllib.request.urlopen(url))

rag = [s for s in data["sites"]
       if s["verified"] and "RAG 检索" in s["tags"]]
for s in rag[:10]:
    print(s["name"], s["url"], s["verified"]["stars"])
const res = await fetch('/data/sites.json');
const { sites, counts } = await res.json();
const rag = sites.filter(s => s.verified && s.tags.includes('RAG 检索'));
console.log(counts.sites, 'total /', rag.length, 'RAG sites');
数据来自 cyberMap 每日收录流水线 · 分类与标签同站内导航一致 · 验证证据由 api.github.com 与 HTTP 实探生成，stars 以 API 为准。
