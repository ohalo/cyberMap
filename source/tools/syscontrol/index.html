SysControl — 局域网一键远程关机

两台电脑（Windows / macOS / 飞牛 NAS）各跑一个 Flask 关机 Agent，安卓 App 发带 Token 的 HTTP 请求触发关机。纯局域网、免费、可控，不依赖任何第三方云服务。

版本 v1.0.0协议 HTTP + TokenAgent: Python 3 / Flask App: Kotlin / Compose（minSdk 33）开源 · 源码可审计

安装与使用四步

  1. 下载并安装：手机上点上方下载按钮（或用手机浏览器打开仓库 releases/ 目录），下载完成后点 APK 安装，允许「未知来源」。
  2. 同一局域网：手机和要控制的电脑连同一个 WiFi / 子网。按上文把对应系统的 Agent 装好、改好 config.json 里的 token。
  3. 添加设备：打开 App → 点右上角刷新图标自动扫描（发现设备后填 token 配对），或点「+」手动填名称 / IP / 端口 / token。系统类型默认自动识别。
  4. 关机：设备卡片上绿灯表示在线，点卡片上的「关机」单独关这台；底部红色「一键全部关机（N 台在线）」并发关掉所有在线设备。
为什么不下载就找不到？：App 靠 mDNS 广播发现 Agent。如果路由器开了 AP 隔离或跨 VLAN 导致扫描不到，用「+」手动填电脑的局域网 IP 即可，功能完全一样。

App 界面（依据 Ardot 设计稿绘制）

下面是根据 SysControl 安卓端界面设计稿绘制的界面示意，展示四个主要场景。实际界面以 APK 运行效果为准。

它解决什么

电脑开着机却人在床上、在客厅、在另一个房间——不想为了关机专门走一趟。现成方案要么要装一整套远控软件、要么依赖公网账号，SysControl 走的是另一条路：

  • 只在局域网内工作：手机和电脑连同一个 WiFi，请求不出路由器。
  • 零服务费、零账号：代码在你自己机器上跑，配对密码你自己设。
  • 一套 Agent 通吃三端：Windows、macOS、Linux / 飞牛 NAS 共用同一份 agent.py。
  • 安卓端是原生 App：Kotlin + Compose 编写，支持 mDNS 自动扫设备，也能手动添加。
先应答后关机：Agent 收到请求会先回 HTTP 200，延迟 shutdown_delay_seconds（默认 1 秒）再真正关机。所以 App 端不会因为「连接被断开」误判成失败。

工作原理

两个接口构成全部通信：

路由方法鉴权作用
/shutdownPOSTX-Token + IP 白名单调度关机（先回 200，延迟执行）
/healthGETIP 白名单（可选加 Token）返回主机名 / 平台 / 版本，App 用于在线探测

功能特性

Token 即配对密码电脑上设一次，手机配对输入一次即永久保存。非 ASCII 字符会因 HTTP 头编码失效，务必用 ASCII。
IP 白名单纵深防御默认允许 RFC1918 私网段 + 本机，可按家庭网段收窄到 192.168.1.0/24。
防爆破限速同一 IP 60 秒内鉴权失败 5 次，锁定 60 秒并返回 429。
mDNS 自动发现浏览 _shutdown._tcp 自动扫描局域网 Agent；路由器开 AP 隔离时可手动填 IP 兜底。
幂等关机重复点关机返回 already shutting down，不会重复触发。
一键全部关机并发请求所有在线设备，单台失败不影响其他，每台超时 3 秒。
在线状态探测卡片每 5 秒轮询 /health，绿点表示在线。未配免密 sudo 时 Mac 端显示 shutdown_ready: false。
Token 加密存储安卓端用 EncryptedSharedPreferences（AES-256-GCM），不落明文。
中英双语 + 自动识别系统App 按设备系统自动展示 Windows / macOS / Linux 图标，界面支持中英切换。
开机自启macOS 用 LaunchAgent，Linux 用 systemd，Windows 放 Startup 目录，装完重启自动运行。

安装部署

三步走：① 被控端装 Agent → ② 改 Token → ③ 安卓端配对。Agent 一份代码跨平台，按你的系统选下面对应段落。

01 macOS 被控端

唯一额外前提：免密 sudo。Agent 不走 root，也不用在无 GUI 会话下跑 osascript，所以必须给关机命令开一条 NOPASSWD：

echo "$(whoami) ALL=(ALL) NOPASSWD: /sbin/shutdown" | sudo tee /etc/sudoers.d/shutdown-agent >/dev/null && sudo chmod 440 /etc/sudoers.d/shutdown-agent

没配这步时 Agent 不会假装成功：/shutdown 直接返回 503 及提示，/health 里 shutdown_ready 为 false。

然后一键安装（脚本会自动建 venv、装依赖、渲染 plist 里的实际路径、launchctl load）：

cd shutdown-agent
./start_mac.sh        # 首次生成 config.json → 编辑 token → 再跑一次

最后在系统设置 → 网络 → 防火墙里允许 python（venv 内）接收传入连接。坑提醒：macOS 的 5000 端口常被「隔空播放接收器」占用，报 Address already in use 时把 config 的 port 改成 5090 之类，或关掉隔空播放。

02 Linux / 飞牛 OS NAS 被控端

把 shutdown-agent 文件夹拷到 NAS（不要拷 .venv，venv 不可跨平台），运行一键脚本：

./start_linux.sh      # 自动装 python3-venv、重建 venv、装依赖、配 systemd 开机自启

同样配免密 sudo（与 Mac 那条命令相同，/sbin/shutdown）。agent.py 在 Linux 上走与 macOS 同一分支，无需改代码。日志用 journalctl -u shutdown-agent -f 看。

03 Windows 被控端

  1. 装 Python 3（python.org，勾选 Add Python to PATH）。
  2. 以管理员身份运行 install_win.bat：自动装依赖、往 shell:startup 放 pythonw agent.py 快捷方式、添加仅专用网络的防火墙入站规则。
  3. 首次会生成 config.json，编辑 token 后注销重登（或手动跑一次 pythonw agent.py）。

用普通用户运行即可（shutdown 命令普通用户可执行）。不要用 SYSTEM / 计划任务的 SYSTEM 账户——Session 0 里 shutdown 行为不一致。有未保存文档时默认 /s /t 0 可能被应用阻止，要「必关」就开 force_close_apps: true（追加 /f，接受丢数据风险）。

04 安卓遥控器

Android Studio 打开 android-app/（JDK 17，minSdk 33，targetSdk 35），运行到手机。手机与被控电脑连同一局域网即可。

export JAVA_HOME="$HOME/Library/Java/JavaVirtualMachines/jdk-17.0.21.1+2/Contents/Home"
cd android-app && ./gradlew :app:assembleDebug

仓库已带 Gradle wrapper，构建产物 app-debug.apk 约 26MB（含 Compose 调试依赖）。

验证 Agent 是否起来：在电脑上执行 curl http://127.0.0.1:5000/health，返回 JSON 即成功（改过端口就换对应端口）。

如何使用

添加设备

打开 App，两种方式二选一：

  • 扫描设备（推荐）：App 自动浏览 _shutdown._tcp，点发现结果填 token 完成配对。
  • 手动 +：填名称 / 系统 / IP / 端口 / token。路由器开了 AP 隔离或跨 VLAN 导致 mDNS 不可用时用这个兜底。

日常操作

  • 设备卡片上的绿点 = /health 在线（每 5 秒轮询），点大号「关机」按钮单机执行。
  • 顶部「一键全部关机」并发请求所有在线设备，单台失败不影响其他，每台超时 3 秒。
  • 重复点关机不会重复执行——服务端幂等，返回 already shutting down。

curl 直接调用（调试用）

# 查在线状态
curl http://192.168.1.10:5000/health

# 触发关机（把 YOUR_TOKEN 换成 config.json 里的 token）
curl -X POST http://192.168.1.10:5000/shutdown -H "X-Token: YOUR_TOKEN"
配对密码要点：token 是 HTTP 头传输，只能用 ASCII（中文会编码失败）；建议 ≥8 位、不易猜；每台电脑可设相同或不同 token。改完 token 要重启 Agent（App 端也要重新配对）。

config.json 字段

位于 shutdown-agent/config.json，首次运行自动生成。改完重启 Agent 生效。

字段默认值说明
token—必改。配对密码，好记的 ASCII 短密码，建议 ≥8 位；每台可相同或不同
host / port0.0.0.0 / 5000只监听局域网，勿做端口映射。macOS 5000 常被隔空播放占用，改 5090 即可
allow_networksRFC1918 + 127.0.0.1CIDR 白名单，按你的网段收窄，如 ["192.168.1.0/24"]
force_close_appsfalseWindows 专用，追加 /f 强制关应用（有丢数据风险）
shutdown_delay_seconds1应答与关机之间的缓冲秒数，保证 HTTP 200 送达
enable_mdnstrue关掉后 App 只能手动添加设备
health_requires_tokenfalse严格模式：/health 也要 token

安全提醒

这是个能关掉你电脑的工具：部署前确认网段可信、token 够强，别把它暴露到公网。
  • IP 白名单只是纵深防御，不能替代 Token 鉴权；同网段设备仍可访问 /health（信息泄露面很小：主机名 / 平台）。
  • 只在可信局域网用；勿对 Agent 做公网端口映射。需要远程时走 WireGuard / Tailscale 再访问。
  • 路由器给被控电脑做静态 IP 绑定，避免 IP 漂移导致白名单误伤。
  • Windows 不加 /f 时，有未保存文档的应用可能阻止关机；开 force_close_apps 就要接受丢数据风险。
  • 生产可选：用 waitress 替换 Flask 内置服务器（Windows 更稳）——pip install waitress，serve(app, host=..., port=...)。

已验证范围

agent.py 离线测试通过（token / IP 双因子、401 / 403 顺序、调度命令正确、重复请求幂等，关机命令打桩不真关）。Android 工程 assembleDebug 编译通过并产出 APK，装机行为尚未实测——这是当前已知的验证边界。
